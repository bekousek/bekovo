# Přiložené soubory k OSV

Sem patří vlastní pracovní listy, karty, scénáře a další soubory k položkám
v `src/content/osv-items/`. Odkazují se cestou od kořene webu:

```json
"files": [
  { "label": "Karty s emocemi (A4, na rozstříhání)", "href": "/osv-soubory/emoce-karty.pdf", "type": "pdf" }
]
```

Alternativa pro velké soubory je odkaz na Google Drive — `href` pak je plná
`https://…` adresa. Soubory v tomto adresáři se nasazují spolu s webem, takže
sem nepatří nic, co nemá být veřejné.
